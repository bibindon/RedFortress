# Quaternius CC0 assets used in the World 1 base

The generated `base_decor.x` uses source models from the following Quaternius packs:

- Simple Nature Pack: <https://quaternius.com/packs/simplenature.html>
- RPG Essentials Pack: <https://quaternius.com/packs/rpg.html>

Both packs are published under CC0. The original selected `.blend` files are stored
in `source_quaternius/` so that `_build_base_hub.py` can regenerate the DirectX X
assets through Blender's official DirectX X exporter.
