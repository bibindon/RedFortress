# Quaternius Pirate Kit

The pistol, cutlass, and atlas texture in this directory come from the Quaternius Pirate Kit.

- Source: https://quaternius.com/packs/piratekit.html
- Download folder: https://drive.google.com/drive/folders/1KjMzhVsDcyvYMWeVjZcRfuu8auBLpNi2
- Original files: Weapon_Pistol.blend, Weapon_Cutlass.blend, Atlas_Pirate.png
- License: CC0 1.0 Universal (public domain dedication)
- Retrieved: 2026-07-29

The `.x` files are generated from the original Blender files with Blender's official DirectX X exporter using `tools/PreparePirateWeapons.py`.
