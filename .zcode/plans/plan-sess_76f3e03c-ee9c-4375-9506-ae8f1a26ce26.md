### 手順1：Xファイル・CSV生成（Blender 5.1 を使用）
`PrepareEnemyModels.py` を実行し、既存の `Hoshigirl.blend` から DirectX X 形式でエクスポート。AGENTS.md準拠（公式アドオン `bpy.ops.export_scene.directx_x`、axis_forward=Z / axis_up=Y、BOM無しUTF-8 / CRLF）。

```
"C:\Program Files\Blender Foundation\Blender 5.1\blender.exe" --background \
  --python tools/PrepareEnemyModels.py -- \
  hoshigirl \
  RedFortress2/MultiPassRendering/res/model2/Hoshigirl/Hoshigirl.blend \
  RedFortress2/MultiPassRendering/res/model2/Hoshigirl
```

生成物：`enemy.x`, `enemy.default.x`, `enemy.idle.x`, `enemy.move.x`, `enemy.fast_move.x`, `enemy.attack.x`, `enemy.hit.x`, `enemy.death.x`, `enemy.csv`（全てidleにマッピング）

### 手順2：敵クラス `EnemyHoshigirl` を新規作成
`EnemyKanata.cpp/.h` をテンプレートに、Kanataと同じ構造で作成（BOM付きUTF-8 / CRLF）。

**EnemyHoshigirl.h**
- `EnemyBase` を継承
- `static float GetScale() { return 2.5f; }` （モデル1.6m × 2.5 ≒ 4mのボス）
- `bool IsBoss() const override { return true; }`
- `std::wstring GetBossName() const override { return L"ホシガール"; }`
- ※原点が足元にあるため `GetMeshVerticalOffset()` のオーバーライドは不要（デフォルト0.0）

**EnemyHoshigirl.cpp**（コンストラクタで `EnemyBase` を初期化）
```
EnemyBase(pos, meshId, L"hoshigirl", yaw,
          120,          // maxHp
          1.8f,         // moveSpeed（Kanata同等）
          20.0f,        // viewDistance（Kanata同等）
          1.2f,         // contactRadius（ボス大型）
          4.0f,         // height（スケール後の世界高さ）
          MovementMode::Ground,
          true,         // usesExtendedAnimations（hit/death/attackアニメ使用）
          HitReactionMode::SuperArmor)
```
